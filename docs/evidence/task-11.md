## Hardening continuation — 21 September 2026

The release script now directly runs table regeneration/independent validation plus core, solver and session mutation catalogs before asset and evidence gates. Qualification accepts only typed, checksummed JSON artifacts for the exact clean commit, validates report-specific evidence kinds, requires physical device identity for device reports, listening sign-off for media and an archive checksum for archive reports. Legacy path-only ledgers, stale commits, unknown kinds, invalid timestamps and dirty source are rejected.

Solver and pinned-reference corpus runs use ordered contiguous shards in isolated worker processes. The harness publishes combined output only when every worker succeeds and the result count exactly matches the input. Its behavioral tests cover ordering, worker-failure propagation and empty-input rejection. An eight-worker PR qualification passed all 10,000 seeded states, 46,741 shallow states, eight named cases and both pinned-reference comparisons.

On the current working source, all ten tables regenerated byte-identically and all independent table mutations were detected. All 12 core, 12 solver and 17 session mutations were killed with session sources restored byte-identically. Infrastructure tests pass. Generic unsigned Release analysis succeeds. These are local pre-candidate results; the million-state corpus and a fresh clean full Release plan still must run on the final commit, and external device/media/archive gates remain open.
