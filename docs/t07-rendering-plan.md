## Contract and boundaries

R07/R08/R12/R16 and V02/V10/V14 require A02's 26 visible cubies and 54 stickers, beveled bodies/gaps, neutral lighting, visible interior surfaces during turns, exact layer membership and resting transforms, distinct turn/regrip arrows, no accumulated drift and usable non-color/Reduce Motion alternatives. T07 also includes A01 and A03–A07 provenance/visual qualification. An attractive static cube alone does not satisfy T07.

GuideAction already carries identity, operation, before/after Facelets and from/to CubeOrientation. The renderer consumes that value. It must not solve, mutate canonical input, change a session index, save an acknowledgement or manufacture physical completion. SessionController's GuidePlayback callback reports preview completion only. T08 retains ownership of coordinated media sequencing and final guide integration.

Manual input can be incomplete. Its preview must render the actual explicit center palette and optional cells, with an unmistakable empty-sticker appearance; it must not fill missing entries with solved colors. Semantic color labels remain separate from mathematical Face identity. Practice uses its isolated controller and copied preferences.

Use a SwiftUI UIViewRepresentable around ARView in explicit non-AR mode, automatic camera-session configuration disabled, and a virtual PerspectiveCamera showing front/right/top. This avoids a camera permission dependency for manual/practice rendering. Apply a fixed virtual camera and original procedural lighting/materials; no remote assets or meshes.
4. **Endpoint-first animation tests.** A selected-layer pivot animates the layer as one group; a regrip animates the root. Sample a monotonic presentation timeline to set absolute transforms rather than accumulating frame rotations. On completion, rebuild/snap from exact action.after/toPose data. Long-run sequences, replay, pause/resume, reset, interruption and obsolete callback identity must not drift or advance logical progress. 5. **Visible action semantics.** Add original procedural arcs/arrows and a layer highlight for turns; use a whole-cube outline for regrips. Derive their direction from the same GuideAction. Test every view/front-turn amount and every regrip endpoint, including inverse/half-turn labeling. Add front/top/right color anchors and readable non-color labels. Inspect real rendered before/mid/after frames in light and dark modes; a transform-only test cannot prove arrow visibility or understandable direction.
6. **Reduce Motion and manual preview integration.** Provide labeled static before/after presentation without an endless render loop. Add the real incomplete-draft 3D preview to the existing editor and a solved-cube/checkmark completion graphic. Expose view controls with accessible labels; free preview rotation must return to instruction pose before guidance resumes. Test that viewing changes neither draft revision nor physical acknowledgement. 7. **Remaining original art.** Produce the original icon/vector source and install its actual asset; create three help/onboarding illustrations and six top-neighbor diagrams from the orientation contract. Register original sources/provenance in the existing asset manifest. Keep absent human narration/effects explicitly missing for T08 rather than substituting speech synthesis. A08 store screenshots remain T12 release-build output.

## Next animation increment: concrete test boundaries

Inspected GuidePlayback in SessionController.swift, GuideAction/GuidePlanner, and controllerPlaybackLifecycle before adapter work. The existing protocol supplies immutable action, PlaybackID, restart flag and completion callback. Pause followed by play uses restart=false and a new callback identity; replay uses restart=true. Stop/background must invalidate completion and restore the before-state. Keep these semantics rather than introducing a second physical-progress owner.

First behavioral assertions will target a deterministic presentation timeline with supplied monotonic elapsed time: a 0.5-second before hold; normal quarter/regrip duration 1.2 seconds; normal half duration 1.8 seconds; Slow doubles rotation duration and Fast halves it. Test immediately before/at hold and completion boundaries, pause at fractional progress, elapsed time while paused, resume without a jump, replay from before, replacement/stop invalidation and exactly one completion callback. Timing tests must not sleep in real time. Explicitly test speed configuration separately from onboarding's fixed slow policy.

Then inspect actual scene transforms using planner-created actions. For a turn, select nine cubies in its viewed layer, rotate their bodies and sticker bases together around a zero-centered pivot, and leave the other seventeen fixed. Regrips rotate all twenty-six. Reparent before resetting pivot transforms; snap endpoints from action.after and toPose, and reset to action.before/fromPose on cancellation. Compare endpoints and colors against canonical state independently of interpolation; include inverse/half rotations and long sequences. Do not infer color identity from animated entity positions.

The current manual preview owns its scene in a UIViewRepresentable coordinator. Guidance needs explicit shared scene/playback ownership so SwiftUI updates cannot accidentally reset an active preview. Introduce that integration only with tests for re-render, teardown, obsolete completion and restored comparison. Recorded narration must later gate animation start through T08; an animation-only adapter is not completed audio sequencing. Reduce Motion requires labeled static before/expected-after views and the direction diagram, not merely zero-duration rotation.

These are test/design commitments, not implemented behavior or passing evidence. The static-preview PR regression remains isolated from subsequent Swift edits.

## Reduce Motion implementation boundary after label qualification

The accessibility increment must keep actual reduced-motion rendering static, including the view adapter; merely leaving a continuously hosted animation view at progress zero is insufficient evidence. Use a static SwiftUI representation of the same before/after facelets and pose with visible direction guidance. Keep any renderer math in CubeCore conventions and independently assert visible face/row/column ordering. Add a cancellable one-shot scheduling boundary to the presentation adapter. Reuse the monotonic timeline's hold and configured duration, but request no repeating PreviewFrameSource subscription in reduced mode. Before the deadline, the before-state remains fixed; at the matching completion, show the exact after-state and report preview completion only. Policy-only changes must not save an acknowledgement or overwrite user speed preferences. Cover the policy transition through the real controller, and distinguish injected policy tests from physical system-setting qualification.
